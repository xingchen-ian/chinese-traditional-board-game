升官图

试用本件定为故宫博物院折叠式《升官图》，文物号故 179983。彩选：转「德、才、功、赃」，按格内文字升降。不是按点数一格一格走。

本件

藏品
折叠式《升官图》，故 179983。清光绪，清宫旧藏，造办处制作。
形制
长 31.5 cm，宽 16.5 cm，高 4.5 cm。硬纸板，明黄纸裱面；数张小分图独立包边再黏合。展开如棋盘，折叠如书册。
藏品页
故宫博物院藏品页（撰稿人付超）。本站不嵌馆方大图。

玩法（依藏品页）

转动四面分别刻有「德、才、功、赃」的陀螺，看倒的一面是何字，再按所在格内文字对号入座，定升黜。

如以「白丁」为起点，需遵循「德监生，才案首，功童生，赃不动」的要求。

故宫藏品页。此条已写入逐格表。

三圈总述（依藏品页）

  • 外圈：从白丁到状元的功名出身系列；京县、布政司、外省、按察司、外县、外府、外州等衙门系列。
  • 中圈：六部、都察院、九卿、京府、翰林院等衙门系列。
  • 内圈：太傅、太师、太保。

总述已核。各格细文除白丁外均待核。公开网页图约 1024 像素，不够逐格录全。
