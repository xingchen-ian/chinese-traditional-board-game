揽胜图

这里讨论的是清代图戏《揽胜图》。画册「江山胜览」不在此列。至少有两系，定马不同，不能当成同一印本。

两系

吴陈琰《揽胜图》

吴陈琰，字宝崖。此本常见于《檀几丛书》余集卷下。大家走到同一处「观止」。先到的人主持觞政，最后到的人罚饮一大觥。

定马
么渔父、二羽士、三剑侠、四美人、五缁衣、六词客。

高兆《揽胜图谱》

此本常见于《昭代丛书》。《昭代丛书》丁集目录把它列为卷第四十二。这条目录的公开链接，本页没有附上。

刊印的凡例写的是把彩筹存在公所再分。分角色的止处见玩法：有清人记载，图谱正文还没有对完。

定马
么词客、二羽士、三剑侠、四美人、五渔父、六缁衣。

么、五、六三格不同。二、三、四相同。字宝崖的出处是乾隆《杭州府志》卷九十四，识典书号 HY4719，打开这一卷。识典书号不是哈佛燕京的索书号。

定马对照

着色并标「不同」的三行，是两系定马不一致的地方。最右列是另一个识典书号，定马句还没看到，不要把它填进高兆一列，也不要把它和高兆本算成同一印本。
